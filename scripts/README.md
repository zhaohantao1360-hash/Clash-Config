# Clash Verge Rev 脚本

## ZHT_Clash_Icons_Telegram.js

用于在现有 Mihomo 配置上动态增强策略组，不修改订阅节点本身。

功能：
- 增加 `🇭🇰 香港ISP优选`：匹配 `香港 ISP / HK ISP / Hong Kong ISP` 并自动测速。
- 将 `🇭🇰 香港ISP优选` 放到 `📲 Telegram` 策略组第一位。
- 使用 Qure Color 图标为常用策略组统一配色。
- 不改 DNS、rule-providers 和 rules。

建议搭配：
`mihomo/ZHT_Mihomo_Pro_V3.yaml`

图标来源：
- Qure Color All：Koolson/Qure
- mini Color：Orz-3/mini
- Color+：Orz-3/mini

本脚本当前选择 Qure Color 作为统一视觉主题，因为地区、媒体和策略图标覆盖比较完整。
